# Brotherhood — Project Context

## Что это за проект

Brotherhood — фитнес-сообщество для мужчин. Включает Telegram-бот и сайт на GitHub Pages.

**Компоненты:**
- `Brotherhoodbot/bot.py` — основной бот (активный, 474 строки)
- `Brotherhoodbot/index.html` — сайт (~1.13MB, с base64-встроенными изображениями)
- `Brotherhood - bot/bot.py` — второй бот с расширенными функциями (питание, логин)
- `Brotherhood - bot/Nutrition_bot.py` — бот для питания

**GitHub:** `BrotherHood-Lab/BrotherHood`, файл сайта: `index.html` в корне репо.

## Критически важно: CSS-классы для бота

Бот обновляет сайт через GitHub API, ища HTML по точным строкам. **Эти классы НЕЛЬЗЯ переименовывать:**

```
today-block, today-inner, today-header-row, today-muscles, today-time-block,
today-time-label, today-time-value, today-exercise-list, today-exercise-item,
```

Строки поиска в боте:
- `start_tag = '<div class="today-inner">'`
- `end_tag = '</div>\n  </div>\n</section>'`

Инвентарь (также используется ботом): `#inventory-block`, `#inventory-icons`, `.inv-item`, `.inv-box`, `.inv-label`

## Философия сайта (тон и стиль)

Сайт продаёт **философию**, не функции. Человек должен уйти с ощущением: *«Я хочу быть частью этого»*.

**Уходим от:** пафоса, громких обещаний, инфобизнесового языка, слов: «осознанность», «трансформация», «раскрытие потенциала», «новая версия себя».

**Приходим к:** спокойному взрослому языку, уверенности без пафоса, простым коротким предложениям, ощущению книги, а не рекламы.

**Главная мысль сайта:**
> Brotherhood — это место для тех, кто решил работать над собой всерьёз.
> Не ради идеального тела. Не ради чужого одобрения.
> А потому что каждый день можно стать немного лучше, чем вчера.

**Каждый раздел отвечает на «Зачем?», а не «Что здесь есть?»**

## Направления Brotherhood

- **Тренировки** — сила, выносливость, дисциплина. Тело как надёжная опора в жизни.
- **Питание** — система, которой можно следовать годами. Не диета, не ограничения.
- **Медитация** — тренировка внимания, управление мыслями, присутствие.

- **Мужской круг** — онлайн-встреча раз в неделю. Разговор без осуждения, без попыток что-то доказать.

## Система тренировок (для Excel/бота)

Система баллов по группам мышц (без ограничения 5 баллов — изометрия даёт больше).

**Система приоритета огоньков:**
- 🔥 = 1 огонёк
- 🔥🔥 = 2 огонька
- 🔥🔥🔥 = 3 огонька (макс одно упражнение на группу в день)
- 2🔥🔥 + 3🔥🔥🔥 нельзя вместе, остальные комбинации можно
- **За день не больше 4 огоньков суммарно**

**Типы упражнений:** динамика, изометрия, кардио (кардио — зелёным).

**Нужно в Excel:**
- Отдельные графы: кол-во подходов + тип упражнения
- Статистика за неделю: кол-во тренировок, общее время, баллы по группам мышц
- Питание: синхрон с календарём + статистика за неделю

## Безопасность — НИКОГДА не коммитить

- `.env` — содержит токены
- `Пароль.txt` — пароли
- `*API*.txt` — токены Telegram бота
- `Brotherhood - bot/.env` — отдельный .env второго бота
- `Brotherhood - bot/Пароль.txt`

**Токены/ключи никогда не пишутся строкой прямо в `.py`-файлах** — только
`os.environ["ИМЯ"]` (без дефолтного значения-заглушки в виде реального
секрета). 2026-09-01 так утёк токен Telegram-бота и GitHub PAT из
публичного на тот момент репозитория — оба пришлось отзывать. Сейчас
стоит git-хук (`.githooks/pre-commit`, `core.hooksPath=.githooks`),
который блокирует коммит при обнаружении похожего на токен значения —
не пытайся обойти его `--no-verify`, а убирай секрет из кода.
