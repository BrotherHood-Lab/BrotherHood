# 武道 Brotherhood Nutrition Bot

Telegram-бот для напоминаний о питании, воде и тренировках.

## Деплой на Railway

1. Зайди на [railway.app](https://railway.app) → войди через GitHub
2. **New Project** → **Deploy from GitHub repo** → выбери `Brotherhood-bot`
3. В настройках сервиса добавь переменную:
   - `TELEGRAM_TOKEN` = твой токен от @BotFather
4. Railway автоматически задеплоит

## Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | Главное меню |
| `/plan` | План на сегодня (макросы + расписание) |
| `/water` | Трекер воды |
| `/cabinet` | Ссылка на кабинет питания |

## Напоминания (Bangkok UTC+7)

- 08:00 — Завтрак
- 10:30 — Электролитный коктейль
- 13:00 — Обед
- 15:30 — Предтрен еда (только тренировочные дни)
- 16:45 — Тренировка (только тренировочные дни)
- 18:00 — Протеин (только тренировочные дни)
- 19:30 — Ужин
- 23:00 — Казеин
- Вода — каждые 2 часа (08:00–22:00)
